# 프론트엔드 스터디 1주차

### 프론트엔드는 다양한 언어들로 구현되며, 크게 3가지의 언어가 있다. 
- HTML: 무엇이 있는지를 구현
- CSS: 어떻게 보이는지를 구현
- JavaScript: 어떻게 동작하는지를 구현

HTML은 웹페이지에 어떤 것들이 있는지(제목, 글, 이미지 등)를 브라우저에게 알려주는 역할이며, CSS는 그것들의 디자인을 구현하는 언어이다. 그리고 이렇게 구현한 것에 어떤 동작을 취하게 할지를 구현하는 언어가 JavaScript이다. 이를 웹페이지에서도 직접 실행해볼 수 있는데, cmd+option+i키로 개발자 도구 -> console로 들어가

```
document.querySelector("h1").textContent = "안녕하세요!"
```
를 입력하면 querySelector("h1")가 h1을 찾아주고, textContent = "안녕하세요! 가 텍스트를 안녕하세요로 대체해주어, 웹페이지의 정보를 바꾸어 볼 수 있다. 여기서 JavaScript는 DOM을 사용하여 웹페이즈의 요소를 찾거나 바꿀 수 있다.

마지막으로, JavaScript에서 사용자의 행동(클릭, 스크롤 등)은 Event로 취급한다.
