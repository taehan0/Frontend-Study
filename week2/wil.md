# 프론트엔드 스터디 2주차

### 이번 주에는 React로 인스타그램 같은 게시글 화면을 만들어 봤다.
- React: 화면을 컴포넌트(함수)로 나눠서 만드는 라이브러리
- JSX: JavaScript 안에서 HTML처럼 화면을 쓰는 문법
- Vite: React 프로젝트를 만들고 실행해주는 도구

1주차에는 HTML, CSS, JS 파일을 따로 만들었는데, 이번에는 `App.jsx` 안에서 `App`이라는 함수가 화면을 리턴하는 방식이었다. HTML이랑 거의 똑같이 생겨서 처음에는 헷갈리지 않았지만, 다른 점이 몇 개 있었다. 대표적으로 HTML의 `class`가 JSX에서는 `className`이다.

가장 신기했던 건 변수를 화면에 바로 넣을 수 있다는 점이다. 함수 위쪽에

```jsx
const username = "eden";
const likeCount = 8888;
```

처럼 값을 적어두고, 화면에서는 `{username}`처럼 중괄호로 가져다 쓴다. 그래서 HTML을 하나하나 고치지 않아도 위쪽 변수만 바꾸면 이름이나 좋아요 수가 한 번에 바뀐다. `likeCount.toLocaleString()`을 쓰면 8888이 8,888처럼 쉼표까지 붙어서 나오는 것도 알게 됐다.

그리고 `npm run dev`로 서버를 켜두면 코드를 저장할 때마다 새로고침 없이 화면이 바로 바뀐다. 직접 값을 바꿔보면서 결과를 바로 볼 수 있어서 재미있었다. 이미지는 `public/images` 폴더에 넣고 `/images/파일이름`으로 불러온다는 것도 배웠다.
